# Repository guide — COSC 314

## Layout

| Path | Purpose |
|------|---------|
| `Project 1/Project 1/` | BlueJ project — `Relation.java`, `sample-relation.txt` |
| `Project 2/Project 2/` | BlueJ project — `DijkstraExample.java` |
| `archive/course-materials/` | Homework and note PDFs |
| `docs/` | Readable project write-ups and indexes |

## BlueJ (course default)

1. Install [BlueJ](https://bluej.org/).
2. **Project → Open Project** → select `Project 1/Project 1` or `Project 2/Project 2`.
3. Right-click the class → **void main(String[] args)**.

## Command line

**Project 1** — run from `Project 1/Project 1` and enter `sample-relation.txt` when prompted:

```bash
javac Relation.java
java Relation
```

**Project 2:**

```bash
javac DijkstraExample.java
java DijkstraExample
```
